# 👋 Olá, eu sou Vinicius Trembulak

Trabalho com **automação e infraestrutura de varejo**: mantenho e automatizo frentes de caixa (PDVs) em Linux, integro sistemas via APIs de marketplaces de delivery e desenvolvo ferramentas internas em Python.

## 🛠️ O que eu faço

- 🖥️ **Automação de PDVs** — scripts para configurar, sincronizar e atualizar dezenas de caixas de uma vez (SSH/SFTP, Shell, systemd), além de ajustes de tela touch e dual monitor em Linux.
- 🔌 **Integração de APIs** — coleta e consulta de pedidos e status em plataformas de delivery (iFood, Site Mercado).
- 🌐 **Web com Django** — estudos e protótipos de aplicações web, como um app de controle de quilometragem.
- 📝 **Documentação técnica** — runbooks e procedimentos para que as soluções possam ser reproduzidas pela equipe.
